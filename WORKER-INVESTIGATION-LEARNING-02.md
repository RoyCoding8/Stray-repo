## Acceptance counterchecks: mistakes to prevent

| Recurring failure | Required countercheck |
|---|---|
| Live bytes replaced by authored content | Follow provider response bytes through source artifact, child, admitted action and scored effect; substitution/disconnection must affect behavior or be refused |
| Prompt advice reported as executable learning | Invoke retained executable improvement behavior and prove a changed downstream decision, then repeat after process replacement |
| Fixed task panels reported as autonomous agenda | Give only mission plus admissible environment frontier; show observation-dependent choice of next investigation/intervention |
| Assessor semantics weaker than runtime | Execute a candidate requiring legal model/tool/construction effects in both profiles through the same owner |
| Error receipts or spend disappear | Exercise timeout, decode failure, nonzero captured cost plus error, receipt refusal, restart and export; preserve identity and unresolved exposure |
| First arm consumes later arm's acquisition budget | Reserve arm quotas; reverse arm order and verify the same admissible construction allowance |
| Protected data leaks under a different key | Search for literal held-out values in complete model inputs and child views; test indirect policy/state/context routes |
| Candidate answers grade themselves | Independent instrument/scorer derives outcomes; a forged witness cannot earn utility without legal observations/execution |
| “Retained” means only a database row | Reload selected bytes in a new process and use them; trace later candidate generation under the inherited improver |
| Offline verification trusts labels | Tamper identity, content, membership, costs and results separately; derive verdicts from frozen inputs and declared measurement evidence |
| Weak baseline manufactures gain | Prove the authored learner functions on development tasks and has the same legal tools; report baseline failures explicitly |
| Test artifacts disappear with temporary directories | Commit every required driver/fixture; reproduce from a clean checkout after lane directories are removed |
| “Done” merges incompatible evidence levels | Give separate mechanism, live availability, task utility, transfer and meta-improvement verdicts at the actual tested SHA |
