## Behavior

Packet strips sealed keys and labels at the boundary. Decision and construction packets filter sealed observations. Construction tasks freeze without hidden answers, so perturbation leaves the provider request unchanged. Visible context refuses sealed and protected references.

Learner builds the provider prompt from the filtered packet only. Model propose reuses that prompt, so sealed bytes never enter constructors. Exposure appends s09_assessment_exposure with retired_at. Retired batches refuse descendants.

Records persists revision proposals in command_journal keyed by a deterministic proposal id. Retry reuses the id. A different parent or task mints a new id. Freeze stores the candidate digest and bytes before assessment. A second freeze with different bytes refuses and demands a new revision. Assess executes frozen bytes out of process on named tasks and returns bind or reject. Execution identity binds investigation, logical action, policy, method, and attempt.

Selection keeps legacy first match only when no binding context exists. With a dsn or an active binding it consults the newest eligible capability_releases row in default or limited disposition. Fallback names the incumbent when no bound member exists. Bind runs inside one serializable transact against the expected versions. A stale expected raises StaleBind and preserves the old row.

The AD01 protected-task guard stays under its original protocol. Admit still reports admitted for reference-free proposals. Execution still refuses protected targets with zero spend.
