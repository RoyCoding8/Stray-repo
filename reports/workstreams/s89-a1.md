# S89-A1: advertised method operations made executable

Branch `wt/s89-a1-contract` from `20dc163`. Owned paths only:
`experiments/ad01/packet.py`, `experiments/ad01/method_exec.py`,
`tests/test_s89a1_*.py`, this report.

## Defect (confirmed independently)

`packet.public_operations` advertised bare `reduce_graph(...)` and
`reduce_software(...)`. The child driver in `method_exec._DRIVER` bound
only the `reducers` module, so any candidate using the advertised bare
names died with `NameError`. Reproduced before the fix through the real
child path (`run_member_out_of_process`, out of process, no fakes):

- `NameError: name 'reduce_software' is not defined`
- `NameError: name 'reduce_graph' is not defined`

Failing-before run of `tests/test_s89a1_contract.py`: 4 failed, 2 passed.
The 2 passes (direct `oracle.query` use, malformed envelope rejection)
showed those paths already worked.

## Fix (at the source, executor-owned)

`method_exec.child_contract()` (version `ad01-child-v1`) is now the one
table owning the callable contract: signatures, return shapes, origin
labels, and the `reducers.*` binding for each helper. Both consumers
derive from it:

- Prompt exposure: `packet.public_operations` builds its entries from
  `child_contract()`. Offered names and signatures are byte-identical;
  each entry gains an `origin` label (`authored-supplied-rpr01` for the
  helpers, `host-oracle` for `oracle.query`), so authored helper
  behavior stays labeled in the rendered prompt.
- Runtime bindings: the child driver renders wrapper functions and
  `module.__dict__` bindings from the same table, delegating to the
  existing `reducers.reduce_graph` / `reducers.reduce_software`. The
  legacy `reducers` module binding is kept: existing carried sources
  (`reducers.reduce_*` in C3 qualification and several suites) still run.

Untouched on purpose: entry contract, result envelope, oracle semantics
(host `BudgetedOracle` still caps and measures queries; the driver
reports host-measured `queries_used`, so a helper `max_queries` above
the entry budget cannot inflate accounting), legality checking, and the
`authored` flags on seed vs acquired members.

## Remaining gaps

- Archived live candidates were not re-executed here; that diagnostic
  belongs to lane A2 on the corrected path.
- The fix proves the namespace; it proves no learning claim. A generated
  wrapper delegating its whole strategy to an authored reducer still
  counts only as valid execution, not a novel algorithm; retention
  labeling (`authored: False` on acquired members vs `True` on seeds)
  is unchanged and should be read with that caveat.
