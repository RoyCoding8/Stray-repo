## What was built

One thin study controller in `experiments/coord02/` per DEC-EC02-01:
`schemas.py` (versioned step transport + strict parse),
`policy_exec.py` (broker sandbox-exec transport with receipt-backed
restart), `controller.py` (phase ownership, admission-before-inference
loop, binding/eligibility, revalidation, S-fallback, L/W/E seams).
Reused without copying: `representation.canonical_bytes/sha_hex`,
`team.propose_team_plan/submit_child/assemble_and_join/freeze_candidate/
revise_team_plan`, broker `ensure/dispatch/admit_receipt/request_cancel`,
`artifacts.stage/publish/verify_bytes`, `capabilities.publish_candidate/
quarantine_status/quarantine`. No new scheduler, registry, or solver
clone. No migration: the operation ledger + receipts + team/capability/
artifact tables already carry every record the path needs, so no
`migrations/0015_*` was created (reuse preferred per assignment).

Causal order enforced: policy step -> strict validate ->
`team.propose_team_plan` -> dispatch admitted children -> constructor
bytes -> `submit_child` -> `assemble_and_join` -> `freeze_candidate`.
EC-03 proves a refused plan dispatches zero child inference (factory
uncalled, child-op count unchanged). The controller renders the join
type/owner from the admitted shape (`accept`/`select-one`/`conjunctive`)
while keeping the task's checks; task join_rules therefore only need to
carry check bytes (see request R1).

Phase (controller-derived from receipts + team tables, never from
procedure memory): pre-plan `probe|plan|unsupported|stop`, post-probe
`plan|unsupported|stop`, post-fail-join `probe|rework|stop`,
post-fail-probe `rework|stop`, then terminal. At most one probe batch
per stage (<=4 calls, each its own broker op with raw attributed
observation), one initial plan, one rework round; the post-rework join
is terminal. S-fallback runs only pre-plan from predeclared frozen
bytes through the same admit/dispatch/submit/join path on the remaining
allocation; post-plan there is no fresh S episode.

Bounded failures map to explicit statuses with attributable
liabilities, never authored success: `policy-timeout`, `policy-empty`,
`policy-oversize`, `policy-invalid` (unknown action, extra
effect-bearing fields, malformed, echo mismatch), `budget-exhausted`
(step ceiling or `INSUFFICIENT_RESOURCES`), `cancelled` (op
`cancel_state`), `plan-refused`, `submit-refused`,
`join-failed-terminal`, `stopped`/`unsupported`, `stale-inputs`
(package bytes / task snapshot / bindings / quarantine changed
mid-episode), `s-fallback-success`/`s-fallback-failed`.

## Interface signatures for L / W / E

Lane L (construction + frozen use):

- `build_experience_packet(dsn, *, run_id, task_id, investigation_id)
  -> {packet_version: "coord02-experience/1", decisions, probe_observations,
  plans, submissions, joins}`
- `construction_call_spec(packet, budget) -> {abi, action_semantics,
  transport_examples (shape-only, no strategy), development_observations,
  budget}`
- `load_frozen_package(dsn, artifacts_root, version_id)
  -> {version_id, package_digest, entry_bytes, requires}` (verifies bytes,
  refuses quarantined)
- `stage_package(staging_root, *, entry_bytes, description, requires)
  -> receipt`; `publish_package_version(dsn, artifacts_root, receipt,
  launcher, allocation_id, *, version_id, requires) -> CommandResult`

Lanes W / E (task rendering + episode operation):

- `seed_episode(dsn, tag, snapshot, authorized=100000)
  -> {allocation_id, investigation_id, snapshot_digest}`
- `EpisodeConfig(run_id, task_id, allocation_id, investigation_id,
  snapshot, interface_contract, join_rules, bindings[{name,path,abi,
  version}], source_interfaces{name: script_bytes},
  package{version_id, package_digest=sha256(entry_bytes), entry_bytes,
  requires{role: {digest,abi,version}}}, snapshot_digest,
  max_steps=8, step_timeout_ms=2000, probe_timeout_ms=5000,
  s_fallback_outputs=None)`
- `run_episode(dsn, cfg, launchers, child_factory, progress=None)
  -> outcome`; `resume_episode(...)` identical (restart-safe from
  recorded receipts; `progress(status)` is the operator hook, raising
  there simulates kill)
- `child_factory(node_id, child, rendered_obligation) -> {path: str}
  | None` (`None` = disconnect control; lane E supplies live
  model-generated bytes here)
- `render_task_input(cfg, *, observations, accepted_plan, residual,
  remaining) -> X_t`; `render_child_obligation(child, observations)
  -> {...}` (public contract IDs + admitted observation refs only;
  learned source never appended)
- `derive_status(dsn, cfg) -> {phase, plan_id, revision, frozen,
  join_passed, join, decisions, observations, steps_used, sentinel,
  ...}`; `check_bindings(snapshot, bindings, requires, dsn, version_id)
  -> {ok, reason?}`; `list_step_receipts`, `list_probe_observations`
- `outcome = {status, reason, run_id, task_id, plan_id, revision,
  candidate_digest (only when join passed), steps, probe_calls,
  liabilities[{party, reason, operation}], live_source, carried?,
  invalidated?}`; `run_s_fallback(dsn, cfg, launchers, prior_status,
  prior_reason)`
- Transport: `build_request(*, decision_id, package_digest,
  source_digest, plan_revision, phase, allowed, state, task)`,
  `validate_response(response, *, decision_id, package_digest,
  source_digest, plan_revision, phase, allowed)`,
  `parse_response_bytes(raw, **echo)`, `invoke_policy_step(dsn,
  launcher, *, run_id, task_id, seq, entry_bytes, request,
  allocation_id, attempt_id=None, timeout_ms)`,
  `run_probe_call(dsn, launcher, *, run_id, task_id, seq, idx,
  interface, interface_bytes, call_input, allocation_id, ...)`.
  Response top-level keys are fixed; proposal keys are fixed per
  action; state <= 16 KiB; messages <= 64 KiB.

## G0 findings applied without shared edits

- `team.submit_child` takes `plan_id` from the command payload, not
  the argument list; the controller always passes it.
- A `single` plan requires join `accept`; task-supplied join type is
  therefore shape-derived (above), not passed through.
- `revise_team_plan` carries only when inputs, output contract and
  interface contract all match; the controller passes the live
  contract so changed deps invalidate carried work (EC-06), and never
  re-dispatches carried children (their copied submissions stand).
- Failed joins record a candidate digest the controller never reports
  as freezable: `candidate_digest` is set only on a passing join.

## Limits

Local subprocess execution is not containment evidence; `alternatives`
shape admission is implemented but exercised end-to-end only for
`single`/`decompose`; probe interfaces in tests pin source bytes
inside the interface script; step/probe timeouts default to 2 s/5 s;
8 policy steps per episode.
