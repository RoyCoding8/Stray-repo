# Task c02-t19

Program ABI: read one JSON object from the request file named by the first command-line argument, write one JSON object to the response file named by the second. Use only the Python standard library.

Input object: a and b hold strings. Output object: text, a then the configured separator '-' then b, in that order. compute.py holds the defect. Edge cases are graded: empty lists, zero and missing values, exact boundary values, and repeated entries must all be handled.
