# Task c02-t17

Program ABI: read one JSON object from the request file named by the first command-line argument, write one JSON object to the response file named by the second. Use only the Python standard library.

Input object: nums holds a list of numbers, threshold a number. Output object: count, the number of entries strictly greater than threshold. compute.py holds the defect. Edge cases are graded: empty lists, zero and missing values, exact boundary values, and repeated entries must all be handled.
