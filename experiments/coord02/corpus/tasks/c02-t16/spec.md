# Task c02-t16

Program ABI: read one JSON object from the request file named by the first command-line argument, write one JSON object to the response file named by the second. Use only the Python standard library.

Input object: nums holds a list of numbers, k a non-negative window. Output object: total, the sum of the last k entries of nums (all of them when k exceeds the length, 0 when k is 0). compute.py holds the defect. Edge cases are graded: empty lists, zero and missing values, exact boundary values, and repeated entries must all be handled.
